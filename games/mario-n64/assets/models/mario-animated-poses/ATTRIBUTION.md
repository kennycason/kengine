# Animated Mario pose source

- Title: `Mario 64 Oddysey All Animations Final Ver 2025`
- Author: [Skelenius507](https://sketchfab.com/elpocho.voitier)
- Source: [Sketchfab](https://sketchfab.com/3d-models/mario-64-oddysey-all-animations-final-ver-2025-02f241e786e74b9296d45eea55afed63)
- Model license: [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/)

These N64-ready COLLADA files were produced from
`games/mario-3d/assets/models/Mario64Animated.glb`. The reusable
`tools/bake_glb_pose.py` utility samples the source skeleton offline; Assimp
then converts each static pose to COLLADA. Mario N64 currently uses idle, two
walk poses, two run poses, jump, and fall.
